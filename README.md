# Employee Turnover Prediction using Machine Learning & Streamlit 🚀

## 📌 Project Overview

Employee attrition is one of the major challenges faced by organizations. High employee turnover leads to increased recruitment costs, reduced productivity, and operational inefficiencies.

This project focuses on building and deploying a Machine Learning-based Employee Turnover Prediction System capable of predicting whether an employee is likely to leave the company based on various HR-related factors.

The project includes:

* End-to-End Machine Learning Workflow
* Data Preprocessing & Feature Engineering
* Exploratory Data Analysis (EDA)
* Model Building & Evaluation
* Streamlit Web Application Deployment

---

# 🎯 Objective

The primary objective of this project is to:

* Analyze employee-related data
* Identify factors affecting employee attrition
* Build predictive ML models
* Deploy the best-performing model as an interactive web application

---

# 🧠 Machine Learning Workflow

## ✔ Data Collection

* HR Employee Attrition Dataset

## ✔ Data Preprocessing

* Handling categorical variables
* One-Hot Encoding
* Feature Selection
* Data Cleaning
* Train-Test Split

## ✔ Exploratory Data Analysis (EDA)

* Employee satisfaction analysis
* Salary distribution analysis
* Department-wise attrition trends
* Work-hour analysis
* Promotion & retention analysis

## ✔ Model Building

Implemented multiple Machine Learning models including:

* Logistic Regression
* Random Forest Classifier
* Gradient Boosting Classifier

---

# 🏆 Best Performing Model

✅ **Random Forest Classifier**

The Random Forest model achieved the best performance with strong classification capability and high ROC-AUC score.

---

# 📊 Model Evaluation Metrics

The model was evaluated using:

* Accuracy Score
* Precision Score
* Recall Score
* F1 Score
* Confusion Matrix
* ROC-AUC Score

- ✅ Enter employee details

# ▶️ How to Run the Project Locally

## 1️⃣ Clone Repository

```bash
git clone <https://github.com/Mozammil-Ansary/Employee_Turnover_Prediction_ML_Project/>
```

---

## 2️⃣ Navigate to Project Folder

```bash
cd Employee_Turnover_Prediction
```

---

## 3️⃣ Install Required Libraries

```bash
pip install -r requirements.txt
```

---

## 4️⃣ Run Streamlit App

